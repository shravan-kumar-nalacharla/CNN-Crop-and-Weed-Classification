# Measured full-run outputs

Completed 13 October 2026 on local Windows CPU, seed 42, batch 4, three frozen-head epochs plus two block5 epochs. Accuracy 97.71%, test loss 0.0760, AUC 0.9918 on 831 held-out images. These files are generated by scripts/train_vgg16.py and are the sole source for the Results report, presentation and executed review notebook. training_history.json retains original measured epoch values; editable presentation charts round values to six decimals for Excel interoperability.

Dataset: Kaggle V2 Plant Seedlings, https://www.kaggle.com/datasets/vbookshelf/v2-plant-seedlings-dataset ; original Aarhus dataset and Giselsson et al., https://arxiv.org/abs/1711.05458 . Plant photographs in sample/error grids are resized dataset images, attributed to the dataset authors under CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0/ . Raw image files are excluded. Splits are disjoint by image path; repeated plant identities and controlled backgrounds limit field generalization.

The trained model remains local under models/best_vgg16_crop_weed.keras. Smoke and environment diagnostics are excluded from the committed measured outputs.
