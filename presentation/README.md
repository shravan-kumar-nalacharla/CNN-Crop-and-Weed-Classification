# Individual ten-minute presentation

Roll_43_VGG16_Presentation_Results.pptx is the revised eleven-slide presentation, inspired by the supplied LSTM and Stacked GRU course references. It follows problem statement, dataset, architecture, hyperparameters, measured results and conclusion. Speaker notes total 600 seconds. Separate accuracy and loss curves, a confusion matrix, class metrics and held-out prediction examples come exclusively from full-run outputs. The earlier Roll_43_VGG16_Presentation.pptx is the original pre-training draft.

After full training completes, run `python scripts/prepare_presentation.py`, then `node scripts/build_presentation.mjs` using the Codex bundled Node runtime and @oai/artifact-tool. Set CODEX_ARTIFACT_RUNTIME and CODEX_PRESENTATIONS_SKILL when their paths differ. The finalizer checks package integrity, native charts/tables, embedded chart workbooks, slide count, geometry, fonts and first-party import. Inspect all rendered .build/deck-results images after a rebuild. This authoring dependency is separate from Python model training. `--draft` creates an internal layout preview only and never overwrites the final results presentation.
